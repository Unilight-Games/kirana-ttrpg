# Kirana TTRPG Online

เว็บเล่น Kirana TTRPG: วิซาร์ดสร้างตัวละคร 8 ขั้น ชีทที่กดทอยได้ และโต๊ะเล่นแบบ Theater of the Mind
ข้อมูลกฎดึงจาก `Kirana Core System TTRPG (V.2)`, `Kins of Kirana V.2`, `Skill & Sorceries`, `Talent & Knowledge Proficiency`, `Starter Set`, `Item All` · คลังคำตั้งชื่อจาก `ภาษาแห่งคีรันนา`

## ใช้งาน
เปิด `index.html` ได้ทันที (ไฟล์เดียว ไม่ต้องติดตั้งอะไร) หรือเปิดผ่าน GitHub Pages ของ repo นี้

ตัวละคร ห้อง และแชตซิงก์ผ่าน Firebase เมื่อเปิดจาก GitHub Pages ถ้าเปิดไฟล์แบบออฟไลน์จะบันทึกในเบราว์เซอร์เครื่องนั้นแทน
ส่วนโต๊ะเล่นร่วมกันแบบเรียลไทม์ใช้ Firebase (Firestore + ล็อกอินนิรนาม) ค่าเชื่อมต่ออยู่ใน `firebase-config.js` และกติกาความปลอดภัยอยู่ใน `firestore.rules`

## เปิด GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch `main` / `(root)` → Save
รอ 1-2 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## โครงสร้าง
- `index.html` หน้าเว็บที่ build แล้ว (ฝังข้อมูลกฎไว้ในไฟล์)
- `src/` ซอร์ส: `shell.html` (โครง+CSS), `core.js` (เต๋า คำนวณ เก็บข้อมูล), `wizard.js`, `sheet.js`, `table.js`, `main.js` · คลังความรู้ (v1.26): `lore.js` (เนื้อหาตำนาน), `library.js` (หน้าตำนาน คลังทักษะ คลังไอเทม แผนผัง), `loreedit.js` (หลังบ้านแก้ข้อความตำนาน), `catalogedit.js` (v1.27: หลังบ้านแก้ไอเทมและทักษะ) · NPC: `npcs.js` (คลัง NPC / Asset) และ `bestiary.js` (v1.27: ผู้คนกับสัตว์ แม่แบบจากเอกสาร พฤติกรรม ของดรอป) · ระบบโจมตีและการใช้ทักษะบนโต๊ะ (v1.28): `fx.js` (เอฟเฟกต์บนแผนที่และป๊อปอัปเต๋าชนกัน) `combat.js` (หน้าต่างโจมตี หน้าต่างป้องกัน ตัดสินผล) `skilluse.js` (แถบสกิล การลากลงแผนที่ การ์ดในแชต) · v1.29: `actions.js` (Action Track ช่อง Swift Basic Cast ของแต่ละหมาก การหักและคืน Action ผลของสภาวะตอนเริ่มและจบเทิร์น) `feats.js` (ทะเบียนความสามารถ: Trait Proficiency ทักษะติดตัว และกระบวนท่าที่มีผลกับการโจมตีและการป้องกัน)
- `tools/` สคริปต์แปลงไฟล์กฎ .md เป็น `data.json` และ `build.py` รวมเป็น `index.html`
- `test/run.js` ทดสอบเดินวิซาร์ดด้วย Playwright

## แก้ไฟล์กฎแล้วสร้าง data.json ใหม่ (ตั้งแต่ v1.22)
ไฟล์กลางที่ `build_data.py` อ่านจากรอบทำงานก่อน ๆ หายไปแล้ว รอบนี้จึงแทนเฉพาะหมวดชุดเริ่มต้นกับคลังไอเทม แล้วคงหมวดอื่นของ `data.json` ไว้
```
KIRANA_OUT=<โฟลเดอร์ชั่วคราว>/ KIRANA_SETS_SRC="<Starter Set - ชุดไอเทมเริ่มต้น.md>" python3 tools/parse_sets.py
KIRANA_OUT=<โฟลเดอร์ชั่วคราว>/ KIRANA_ITEMS_SRC="<Item All.md>" python3 tools/parse_items.py
KIRANA_OUT=<โฟลเดอร์ชั่วคราว>/ python3 tools/splice_data.py
python3 tools/build.py
```
ถ้า Item All มีบรรทัดเพิ่มหรือหายก่อนหัวข้อหมวดใด ให้แก้ช่วงบรรทัด `TOP_FIX` ใน `parse_items.py` ให้ตรงกับหัวข้อหมวดใหม่ก่อน

## คลังคำตั้งชื่อจากไฟล์ภาษา (ตั้งแต่ v1.23)
เมื่อไฟล์ภาษาแห่งคีรันนาเปลี่ยน ให้อ่านคลังคำใหม่แล้วใส่ลง `data.json` เป็น `DATA.names` (หมวดอื่นไม่ถูกแตะ)
```
KIRANA_OUT=<โฟลเดอร์ชั่วคราว>/ KIRANA_LANG_SRC="<ภาษาแห่งคีรันนา.md>" python3 tools/parse_names.py
KIRANA_OUT=<โฟลเดอร์ชั่วคราว>/ python3 tools/splice_names.py
python3 tools/build.py
```
ช่วงหัวข้อของคลังคำแต่ละภาษา วิถีตั้งชื่อ หน่วยคำในรายการ และภาษาตั้งต้นของวงศาอยู่ใน `tools/names_ways.py` · `names_report.txt` ในโฟลเดอร์ชั่วคราวบอกช่วงบรรทัดที่อ่าน บรรทัดที่อ่านไม่ออก และคำที่ตัดออก

## ชื่อ Trait พื้นหลังและ Flavor ของ Trait (ตั้งแต่ v1.24)
ชื่อไทยของ Trait พื้นหลัง 138 ชื่อ Flavor ที่แยกจาก Trait วงศา 28 รายการและจาก Trait พื้นหลัง 5 รายการ อยู่ใน `tools/traits_v124.json`
```
python3 tools/splice_v124.py                                   # แก้ data.json (รันซ้ำได้)
python3 tools/patch_kins_v124.py "<Kins of Kirana V.2.md>" "<ไฟล์ใหม่>" "<ไฟล์สำรองบรรทัดที่แก้>"
python3 tools/build.py
```
ถ้า Kins of Kirana ถูกแก้แล้วอ่านเข้า data.json ใหม่ทั้งหมดในอนาคต ให้รัน `splice_v124.py` ตามอีกรอบ สคริปต์ตรวจว่าเจอข้อความครบทุกจุด ถ้าไม่ครบจะหยุดพร้อมบอกจุดที่หาไม่เจอ

## v1.29 (17 พ.ย. 2026)
Action Track กติกาโจมตีที่ตายตัวขึ้น ทะเบียนความสามารถของตัวละคร Reaction ที่กดครั้งเดียวจบ และแผงบังคับตัวละคร (Non สั่ง 16 พ.ย. 2026 สิบแปดข้อ เขียนต่อบนฐาน v1.28)

**1. Action Track** (ข้อ 2 และ 5)
- ในฉากต่อสู้ทุกหมากมีช่อง 1 Swift 1 Basic 1 Cast ตามไฟล์แกน ช่องที่ใช้แล้วถูกขีดฆ่า เห็นได้ในแผงบังคับ แผงหมากที่เลือก และลำดับเทิร์น · NPC ที่สแตตบล็อกเขียน AP n ได้ 1 Swift กับ AP n ช่อง (เว็บตีความเอง เอกสาร Fauna เขียนแค่จำนวน AP)
- GM คลิกช่องที่ขีดฆ่าเพื่อคืน Action นั้น และกด + เพื่อแจกเพิ่ม ทั้งสองอย่างประกาศในแชต · คลิกช่องที่ยังไม่ใช้เปิดเมนูสิ่งที่ทำได้ด้วย Action นั้น (Maneuver Focus Observe Reload ลุกขึ้น ตั้งหลัก กลิ้งดับไฟ · โจมตี Grab Overwatch ใช้ไอเทม Assist Use Knowledge)
- ระบบหักช่องให้เอง: โจมตีใช้ Basic · เล็งหรือ Focus แบบอื่นใช้ Swift เพิ่ม และทำไม่ได้ถ้า Maneuver ไปแล้ว (อาวุธระยะไกลทำได้เมื่อ Range ถึงระดับ 2) · ย้ายหมากในระยะ Dash ใช้ Swift เกินจากนั้นเป็น Run ที่ถามว่าจะจ่าย Basic หรือ Cast · การโจมตีและการย้ายนอกเทิร์นของตัวเองไม่หัก
- Action หมดแล้วปุ่มทอยและปุ่มใช้ทักษะกดไม่ได้ GM มีช่องอนุญาตเป็นครั้ง ๆ
- เริ่มเทิร์นและจบเทิร์นคิดให้: Bleeding (Deepwound คูณสอง) Burning Poisoned คูณจำนวน Action ที่ใช้ และสภาวะที่ครบอายุ · Perfect Parry กับ Perfect Evade ได้ Swift เพิ่มหนึ่งช่องทันที · ผู้เล่นมีปุ่มจบเทิร์นในเทิร์นของหมากตัวเอง

**2. กติกาโจมตีและป้องกัน** (ข้อ 1 3 4 9 13 14)
- ยิงเกินระยะแม่นหัก 1 CV ต่อทุก 2 เมตรเต็มที่เกิน ข้อความในคำอธิบายศัพท์และ Proficiency ของเว็บเปลี่ยนตาม
- โจมตีประชิดบวก Might ยิงและขว้างบวก Sight ตายตัว ผู้เล่นไม่มีช่องเลือกค่าพลัง GM เปลี่ยนได้เป็นครั้ง ๆ ในตัวปรับเพิ่มเติม
- Rip: ระบบตรวจเองว่าส่วนที่โดนไม่มีเกราะและความเสียหายเข้า HP แล้วเสนอปุ่มในการ์ดผลให้ผู้โจมตีเลือกเปลี่ยนความเสียหายเป็น Bleeding
- Parry Dice มาจากอุปกรณ์และความสามารถ ผู้เล่นไม่มีช่องเลือกจำนวน GM ให้เพิ่มได้ทั้งที่หมาก (สูงสุด 3 อยู่จนกว่าจะลด) และเฉพาะการป้องกันครั้งนั้น
- Parry การโจมตีที่เล็งตำแหน่ง: ดูกลุ่มของเลขที่ผู้โจมตีทอยได้ ตำแหน่งที่โดนยังเป็นตำแหน่งที่เล็ง
- โจมตีจากสถานะซ่อนตัวได้ Advantage และนับเป็น Perfect Strike · ลงมือโจมตีหรือร่าย Sorcery แล้วหลุดจาก Hidden และ Invisible (GM ยกเว้นการร่ายได้) · Invisible นับว่าซ่อนตัวอยู่ตามไฟล์แกน · หมากที่ GM กดซ่อนนับเป็นการซ่อนตัวและถูกเปิดเผยหลังโจมตี
- อาวุธอ่านจากข้อความเต็มใน Item All แม้ชีทจดข้อความย่อของชุดเริ่มต้น กติกาเฉพาะของอาวุธจึงทำงานครบ: ต้อง Focus ไม่งั้น CV −3 · โจมตีด้วย Swift Action · ความเสียหาย ×2 กับสัตว์ · ระยะแม่นเพิ่ม · Guard Break เมื่อ CV สูงกว่า 7 (ตรวจตอนป้องกัน) · สภาวะ On-Hit 27 ข้อของอาวุธในคลัง
- Temporary HP ไม่ทบกันตามไฟล์แกน: มีอยู่แล้วไม่ได้ของใหม่จนกว่าของเดิมจะหมด

**3. Skill Sorcery และ Reaction** (ข้อ 6 7 10 11)
- ทักษะที่มีผลกับตัวผู้ใช้ (104 จาก 317 อัน) ไม่มีช่องเลือกเป้าหมายอื่น GM มีปุ่มเปิดให้เลือกเป้าเมื่อจำเป็น
- ค่าร่ายเป็นตัวเลขตายตัวตามข้อความของทักษะ ผู้เล่นแก้ไม่ได้ · สิ่งที่เปลี่ยนค่าร่ายขึ้นเป็นตัวเลือกที่ระบบตรวจให้ (ไม้เท้าเวท สัญลักษณ์ศักดิ์สิทธิ์ Martial Artist Drain Dry Trickster III Dual Caster Substitution Soul Chamber และผิวกายคือคัมภีร์ของพื้นหลัง Yantra Master ที่ร่ายเวทที่สักไว้ได้วันละครั้งโดยไม่จ่าย MP) · GM แก้จำนวนหรือยกเว้นได้
- ประเภทของทักษะบอก Action ที่ใช้: Cast Swift Basic · [เพ่งสมาธิ] บวก Swift ของการ Focus · [คอมโบ] เป็น Free Action ได้เทิร์นละครั้งเมื่อเป้าติดสภาวะทางกายภาพจากผู้ใช้ · ทักษะที่ใช้ Action ใช้นอกเทิร์นไม่ได้ (GM อนุญาตได้) · ขีดจำกัดจำนวนครั้งต่อการต่อสู้ ต่อการพัก และต่อวันถูกนับ
- Reaction ตอนถูกโจมตี: เป้าหมายคือผู้โจมตีเสมอ ไม่มีช่องให้เลือก · 10 อันที่ระบบรู้ผลเป็นปุ่มกดครั้งเดียวในหน้าต่างป้องกัน ระบบทอยให้ทั้งสองฝ่ายและตัดสินผล (ระบำเหินหาว พันธนาการเงา โล่วายุ ม่านเหล็กกล้า เกราะโลหิต กายาเหล็ก โอบกอดความว่างเปล่า ดูดกลืนอัคคี เปลวเพลิงสัมบูรณ์ ความยืดหยุ่นในความเปราะบาง)
- Reaction หลังป้องกันสำเร็จ 3 อัน (ประกายแสง ไอเหมันต์ ม้วนตัวหลบ) เป็นปุ่มในการ์ดผล เป้าหมายตั้งเป็นผู้โจมตีให้ · Reaction อื่นใช้จากรายการทักษะในหน้าต่างป้องกันแล้วบอกผลเอง · กดป้าย Reaction จากแผงบังคับขณะถูกโจมตี ระบบพาไปที่หน้าต่างป้องกันของการโจมตีนั้น

**4. ทะเบียนความสามารถ** (ข้อ 8 และ 15) ไฟล์ `src/feats.js`
- v1.28 อ่านแค่อาวุธกับข้อความของสกิล Trait ทุกอันจึงไม่เคยเข้าหน้าต่างโจมตี ลีลาวาดอาวุธเป็นหนึ่งในนั้น · v1.29 รวบรวมความสามารถของตัวละครทุกแหล่ง (Trait ของวงศา Hindrance Trait พื้นหลัง Proficiency ทักษะติดตัว กระบวนท่า) แล้วเขียนกติกาทีละอันตามข้อความในข้อมูลของเว็บ
- ตัวเลือกขึ้นในหน้าต่างโจมตีและป้องกัน ระบบติ๊กให้เมื่อตรวจเงื่อนไขได้เอง ที่เหลือผู้เล่นติ๊ก จำนวนครั้งที่จำกัดถูกนับ (ต่อการพักเก็บในชีท ต่อการต่อสู้ ต่อรอบ ต่อเทิร์นเก็บบนหมาก)
- ความสามารถเดียวที่กัน Disadvantage ของการ Evade ประชิดคือ Elven Agility (Trait ของ Day Alves และทักษะติดตัวชื่อเดียวกัน) เป็นตัวเลือกในช่อง Evade ที่ผู้เล่นเลือกเองว่าจะใช้ไหม นับ AGI Mod ครั้งต่อการพักสั้น
- กระบวนท่าที่ตั้งอยู่แสดงในแผงบังคับ ผลเข้าหน้าต่างเอง เช่น จังหวะวัลลาไคสะสม Rhythm Stack เมื่อป้องกันสำเร็จ เพลงมวยบดศิลาสะท้อน 1d3 เมื่อ Parry ประชิดสำเร็จ วารีสะท้อนเงาให้ปุ่มโจมตีฉวยโอกาสหลัง Perfect Parry
- ความสามารถที่เกี่ยวกับการต่อสู้แต่ยังไม่มีกติกา ขึ้นเป็นรายการเตือนในหน้าต่างเดียวกัน ไม่หายเงียบ

**5. หน้าต่างและแผงบังคับ** (ข้อ 12 16 17)
- หน้าต่างโจมตี หน้าต่างป้องกัน และหน้าต่างใช้ทักษะลากย้ายได้จากแถบหัว จำตำแหน่งไว้ ไม่สูงเกินจอ ส่วนเนื้อหาเลื่อนในตัว ปุ่มทอยเกาะขอบล่างของหน้าต่าง ลากออกนอกจอแล้วถูกดึงกลับ
